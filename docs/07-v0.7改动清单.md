# 梦潮：回声航线｜v0.7 独立改动清单

日期：2026-09-27  
范围：提取 v0.7 相比 v0.4—v0.6 的新增、调整和明确项，方便策划、程序、美术对照执行。  
说明：“此前”指旧策划中的规则，不代表已核实的游戏代码。本文是需求变更单，尚未实施代码修改；商业化部分保留为建议方案。

## 1. 改动总览

| 编号 | 模块 | 此前规则或缺口 | 本次改动 |
|---|---|---|---|
| C01 | 默认射击 | 早期版本保留自动瞄准；v0.5已要求基础弹无穿透 | 统一所有飞机为固定向前直射，无自动瞄准、无追踪、无穿透 |
| C02 | 核心升级 | 穿透等属于泛化强化，获取与等级不够明确 | 穿透、追踪成为局内升级奖励，明确三级效果与兼容关系 |
| C03 | 奖励选择 | 已有二选一，但首次候选及地图开奖规则不统一 | 首次固定穿透/追踪二选一；地图抽奖先生成候选，再由玩家选择 |
| C04 | Build槽位 | 主技能、联动技能、大招改造 | 调整为主炮改造链、自动支援、大招改造，兼容主炮能力累积 |
| C05 | 地图交互 | 已有房屋、矿点、NPC互动 | 明确三类物件如何产出升级候选，加入交互保护及兑现反馈 |
| C06 | 关卡结构 | 波次、章节和一次出击边界不统一 | 每章3关，每关独立出击；通关解锁下一关，新局重新Build |
| C07 | 难度推进 | 重点是第一章内部波次变强 | 增加跨关递增难度，同时配置敌群积压控制 |
| C08 | 局外成长 | 飞机天赋为主，共享成长未明确 | 新增共享等级；随机天赋解锁时生成并保存 |
| C09 | 大招容量 | 已有1→2→3次成长，节点时机不明确 | 容量变为固定共享里程碑，首关和第一章通关后分别解锁 |
| C10 | 招募与商业化 | 抽卡与付费边界不明确 | 区分飞机招募、局内选择和地图抽奖，新增两端商业建议 |

## 2. C01—C02：取消默认追踪和穿透，放入升级

### 默认攻击

- 保留自动开火，取消自动找敌人、转炮口和子弹转向。
- 横版固定朝右射击，玩家移动飞机来对准目标。
- 初始穿透次数为0，命中首个有效敌人后销毁。
- 所有飞机与基础分身、僚机遵循同一规则。
- 每次新出击清除局内追踪、穿透、分裂；永久天赋不能直接绕过获取。
- 大招保留飞机专属范围效果，但不能永久改变基础主炮能力。

### 新增升级规则

| 升级 | 1级 | 2级 | 3级 |
|---|---|---|---|
| 穿透 | 同一弹体最多命中2个不同敌人 | 最多命中3个 | 最多命中4个 |
| 追踪 | 缓慢转向前方目标 | 更快转向、更大搜索角 | 目标死亡后可重新搜索前方敌人 |

穿透不附带伤害衰减，每颗弹对同一敌人只结算一次。追踪未找到目标时直飞，1—2级丢失目标后不重新搜索；3级可重新搜索。两种能力可以叠加，选追踪不会覆盖已有穿透。

**验收：**未获得升级时，偏离目标的子弹不拐弯，命中一只即消失；获得后能立即看见攻击行为改变。

## 3. C03—C04：升级抽奖与Build选择

### 奖励流程调整

清波或完成地图互动 → 预告 → 揭晓两个方案 → 飞向其中一个确认 → 图标进入主炮 → 下一队敌人展示效果。

- 首次选择约20—30秒，固定“穿透1 / 追踪1”。
- 第二次：已有方向升级 + 兼容新方向。
- 第三次：至少一个可与已有能力联动的方案。
- 满级、无作用、缺少前置的项目不直接占用候选；两个方案不能重复。
- 房屋转盘和矿点抽奖决定两个候选，不直接替玩家决定技能。
- 大招能量、恢复等资源可以直接领取，改变Build的技能仍需选择。
- 接近候选只预览，进入确认圈停留0.35秒才生效。
- 错过选择则保留机会，下一段安全位置重现。
- 选择时场景减速、危险淡出，不弹全屏选卡页。

### 技能槽调整

| 槽位 | 本次规则 |
|---|---|
| 主炮改造链 | 穿透、追踪、多重等兼容效果累积 |
| 自动支援 | 雷球、分身等；替换时显示前后结果 |
| 大招改造 | 影响飞机专属大招的联动 |

**验收：**既能构筑贯穿爆破流，也能构筑追踪蜂群流；不能把其中一种首选做成唯一通关答案。

## 4. C05：地图交互成为升级入口

| 物件 | 本次明确的操作 | 场景反馈 | 奖励 |
|---|---|---|---|
| 梦灯屋 | 靠近悬停2秒 | 屋内亮灯、屋顶转盘启动 | 主炮改造二选一 |
| 星砂矿 | 灯圈内停留2.5秒 | 矿层爆开、矿道开启 | 兼容强化二选一 |
| 救援站 | 飞过宽光环救出NPC | NPC跟随、后续支援点开启 | 支援技能二选一 |

- 首轮原型优先落实上述三种；风力塔、古钟台作为扩展。
- 交互期间继续自动开火，附近不刷新敌人，提供可见防护圈。
- 通过位置、奖励候选和后续路线变化形成重复游玩差异。
- 不要求画精确圆圈，不增加互动按键。

**验收：**玩家完成互动后，必须同时看见地图改变和实际奖励。

## 5. C06—C07：逐关变强，配合成长继续推进

### 关卡边界

- 1章包含3关，1关是一局约6—8分钟的完整出击。
- 关内波次、互动和洞口连续进行；只在出击结束后结算。
- 通关解锁下一关，失败仍按完成进度获得成长资源。
- 下一关重新开始局内Build，保留永久成长。

### 难度改动

- 每关总压力递增：先提高数量、出兵频率和阵型复杂度，再加入精英，最后小幅提高生命。
- 普通杂兵保持短时击杀；精英和Boss承担持续输出目标。
- 关卡基础配置固定，不跟随玩家成长或付费状态抬高敌人属性。
- 出兵高峰与清理窗口交替，避免持续堆怪造成必输。
- 同屏活跃敌人达到原型上限48只时暂停队列入场。
- 积压超过24只持续3秒时推迟下一队，并提示可用地图设施。
- 普通敌人漏过仅影响额外评分，不连续扣血；主目标不能因为敌人离场而无法完成。

**验收：**下一关更有压力；成长后回打同一关应明显更轻松。

## 6. C08—C09：局外成长与大招容量

### 共享等级

新增账号共享等级，星尘用于提升基础攻击、生命。新飞机继承进度，可以直接试用；不新增装备、配件或洗词条。

原型攻击公式：基础伤害 × 1.06^(等级−1)，上限10级。首关约120星尘，升2级费用100；失败按完成波次结算约30—90。以上均为调试起点，不是最终平衡数值。

### 随机天赋树

- 飞机解锁时生成一次并保存，随机节点排列与正向组合。
- 默认高亮推荐节点，减少比较和配置。
- 穿透/追踪相关天赋只强化本局已获得能力，不能直接提供开局穿透/追踪。
- 大招容量属于固定节点，不参与随机。

### 容量节点

| 进度 | 最大储存次数 |
|---|---:|
| 初始 | 1 |
| 1-1首次通关，解锁首个容量节点 | 2 |
| 1-3首次通关，解锁第二个容量节点 | 3 |

容量账号共享，新飞机继承。每次释放消耗1次，之后继续充能；UI显示库存、容量与下一次进度。Boss入口仅在库存为0时补到1次；满容量后的溢出转少量本局积分。

**验收：**新飞机无需重刷容量；重进游戏不重抽树；局内能力不误存成永久能力。

## 7. C10：商业化新增建议

本节是从v0.7提取的建议方向，不表示已经决定售价、发行方式或接入支付。

| 项目 | 建议 |
|---|---|
| Steam | 买断基础游戏，可选外观及实质内容扩展 |
| 手机 | 免费体验第一章，一次性解锁完整内容 |
| 两端外观 | 涂装、尾焰、表情、地图互动演出主题 |
| 飞机招募 | 首版使用游玩获得的招募券；重复结果转指定飞机解锁进度 |
| 地图抽奖 | 消耗一次地图参与机会，无货币支付 |
| 局内二选一 | 清波或互动获得，不以支付换候选 |

### 商业边界

- 追踪、穿透、大招第2/3次容量通过正常游玩获得。
- 不售卖本次必出技能，不以广告重抽候选，不售卖过关必需属性。
- 外观不能改变伤害、奖励概率或关卡难度。
- 购买预览放在机库，战斗、选择和地图交互中不弹购买页。
- 首版建议不做广告、战令、每日强制签到。
- 第一阶段只制作商业流程原型，不接真实支付。

## 8. 开发交付顺序与检查

| 优先级 | 改动 | 验收重点 |
|---|---|---|
| P0 | 默认弹体取消追踪与穿透 | 开局直射、首次命中销毁 |
| P0 | 穿透/追踪奖励及二选一 | 选择才生效、兼容不覆盖、新局重置 |
| P0 | 房屋/矿点/NPC奖励流程 | 互动、开奖、地图改变连起来 |
| P1 | 第一章3关与共享成长 | 逐关增压、成长后旧关更轻松 |
| P1 | 随机树存档、容量节点 | 保存可靠，新飞机继承共享进度 |
| P2 | 机库外观与内容解锁原型 | 商业展示不打断战斗，不影响数值 |

实施范围：1架飞机、1章3关、穿透/追踪/多重/爆破4种主炮改造、3种地图互动、共享等级及1—3次大招容量。
