# 梦潮 回声航线 Q版美术风格规范

版本：v0.1

文档用途：角色原画、场景原画、UI、特效、动画、宣传图和 Unity 资源制作统一标准

项目类型：2D 手绘横版弹幕动作 Roguelite

目标风格：Q版、可爱、梦幻、轻微诡异、清晰易读

## 1. 美术总方向

《梦潮：回声航线》的美术要让玩家同时感受到三种情绪：

1. 第一眼是可爱和亲近。
2. 进入战斗后是明亮、快速、清晰的动作感。
3. 深入梦境后能感受到轻微的不安和神秘。

推荐比例：

- 可爱感：60%。
- 梦幻感：25%。
- 诡异感：15%。

整体画面采用 Q 版手绘 2D，不追求写实比例和复杂材质，而是通过轮廓、颜色、表情、发光和动作建立辨识度。

## 2. 风格关键词

必须保留：

- Q版大头身。
- 圆润外轮廓。
- 简化结构。
- 明确的大色块。
- 软边发光。
- 手绘纸张纹理。
- 梦境中的漂浮物。
- 可爱与轻微异常并存。
- 弹幕形状清晰。

需要避免：

- 写实人体比例。
- 过度复杂的服装细节。
- 纯黑粗描边。
- 大面积灰褐色画面。
- 角色五官过小。
- 背景比战斗元素更亮。
- 弹幕和特效融成一团。
- 直接模仿其他作品的角色轮廓、配色和构图。

## 3. Q版角色比例

### 3.1 主角比例

主角建议为 2.5—3 头身：

- 头部占角色总高度约 38%—45%。
- 身体占 35%—40%。
- 四肢占 20%—25%。
- 手脚适度放大，便于移动、切弹和受击动画识别。
- 武器和梦灯可以略大于现实比例，增强动作轮廓。

主角缩小到手机屏幕约 36—48 像素高时，仍然要能通过剪影区分。

### 3.2 五官比例

- 眼睛占头部宽度约 22%—28%。
- 两眼间距约为一个眼睛宽度。
- 鼻子使用一点或短弧线表达。
- 嘴巴根据情绪使用小弧线、圆形或张口形。
- 腮红使用半透明圆形，不使用复杂渐变。
- 战斗状态下眼睛亮度增加，危险状态下瞳孔缩小。

### 3.3 角色剪影

每个主要角色必须保留一个主识别物：

- 主角：顶部梦灯和披风尾巴。
- 失控闹钟：巨大圆盘和长指针。
- 镜中兽：对称的双头轮廓。
- 吞梦鲸灯：大嘴、长尾和灯笼身体。
- 完美裁缝：剪刀、线团和长袖轮廓。

## 4. 主角设计规范

主角是“梦灯生物”，不是人类、动物或现有作品角色的直接变体。

推荐外形：

- 圆形或椭圆形主体。
- 顶部一盏小梦灯。
- 两条短而灵活的飘带或耳状装饰。
- 身体下方有一圈柔软的梦雾。
- 攻击时梦灯变亮，移动时留下短拖尾。

基础颜色：

- 身体：暖白或淡粉白。
- 阴影：紫灰或蓝灰。
- 梦灯：金黄。
- 能量：青色和淡紫色。
- 受伤：珊瑚红。

主角不能使用过多深色，否则会和梦境背景融在一起。

至少制作以下表情和状态：

- 待机：放松、轻微微笑。
- 移动：眼睛集中、身体前倾。
- 攻击：眼睛变亮、嘴角收紧。
- 切弹：短促认真表情。
- 完美弹反：惊喜或自信表情。
- 受伤：眼睛变成短线、脸部出现红色提示。
- 濒死：梦灯变暗、身体轻微抖动。
- 通关：闭眼微笑、梦灯向上飘。
- 失败：梦灯熄灭但角色仍然可爱，不使用恐怖表情。

## 5. 角色线稿和上色

### 5.1 线稿

- 线条使用深蓝紫，不使用纯黑。
- 外轮廓比内部线条粗 1.3—1.6 倍。
- 重要动作轮廓允许使用无描边色块。
- 小尺寸资源减少内部线条。
- 线条端点使用圆角。

### 5.2 上色

推荐三层上色：

1. 基础色块。
2. 单一方向的柔和阴影。
3. 重点边缘的梦境高光。

角色不使用过多写实反光。高光只服务于轮廓、武器、梦灯和攻击方向。

### 5.3 阴影方向

默认主光源来自画面上方偏后方的月光或梦灯：

- 角色下方偏紫灰。
- 角色顶部偏暖黄或淡青。
- Boss阴影可以更深，但不能完全压成黑色。

## 6. 敌人和 Boss 规范

敌人遵循“可爱形状 + 异常行为”的设计原则。

普通敌人：

- 形体简单。
- 一眼可以看出移动方向。
- 不使用太多装饰。
- 每种敌人只保留一个主要攻击特征。
- 颜色与主角保持区分。

精英敌人比普通敌人多一个明显识别元素：

- 环绕护盾。
- 发光裂纹。
- 特殊眼睛。
- 反向飘带。
- 不规则影子。

精英敌人不能只是普通敌人放大并换颜色。

Boss需要在画面上占据 20%—35% 的横向空间，同时保证玩家和弹幕可见。

Boss包含四层：

1. 主体轮廓。
2. 情绪核心。
3. 运动装饰。
4. 攻击特效。

### 6.1 失控闹钟

轮廓：

- 大型圆盘。
- 两根明显长指针。
- 侧面有小铃铛或悬挂零件。
- 背后有花瓣、时钟碎片和紫色缎带。

三个乐章颜色：

- 第一乐章：蓝紫色，冷静但不稳定。
- 第二乐章：橙红色，速度和焦虑增加。
- 终章：白金色和深紫色，出现时间倒流。

阶段变化：

- 第一阶段：指针卡住，眼睛和核心闪烁。
- 第二阶段：表盘裂开，内部出现旋转齿轮。
- 第三阶段：时间碎片反向飞行，轮廓出现残影。

## 7. 场景美术方向

游戏采用横版舞台构图：

- 前景：高对比，用于强化玩家边界。
- 中景：敌人和弹幕主要活动区域。
- 后景：梦境城市、海面、浮岛和月亮。
- 远景：朦胧天空、云层、纸张碎片和梦境光点。

### 7.1 失眠之海

首个区域使用：

- 深蓝紫色夜空。
- 漂浮的城堡和桥梁。
- 玻璃质感海面。
- 悬挂灯笼。
- 纸折小船。
- 大月亮和轻雾。
- 远处不断亮起又熄灭的窗口。

每个区域至少制作：

- 远景图 1 层。
- 中景图 2 层。
- 游戏区域装饰 1 层。
- 前景遮挡 1 层。
- 动态粒子 1 层。

背景不能使用过强的纯白或高饱和红色，以免影响弹幕识别。

### 7.2 场景移动

- 远景滚动速度为主场景的 20%—35%。
- 中景滚动速度为主场景的 50%—75%。
- 前景滚动速度为主场景的 100%—120%。
- Boss阶段切换时允许短暂改变滚动方向。
- 视差滚动不能造成画面晕动。

## 8. 弹幕美术规范

弹幕必须优先服务于玩法识别，再服务于装饰。

### 8.1 粉色圆弹

- 轮廓：圆形。
- 内部：柔和渐变和小高光。
- 运动：直线、弧线或缓慢旋转。
- 颜色：粉红、珊瑚、玫红。
- 反馈：命中后产生小型粉色碎片。

### 8.2 蓝色菱形弹

- 轮廓：四角菱形。
- 内部：清晰的蓝色核心。
- 运动：可以旋转，但不能模糊边缘。
- 颜色：青蓝、冰蓝。
- 切弹后：裂成两片蓝色碎片，再转为玩家颜色。

### 8.3 金色星弹

- 轮廓：四角或六角星。
- 内部：强亮点。
- 运动：靠近玩家时产生危险圈。
- 弹反后：变为金色音符、星屑或音波。

### 8.4 白色预警线

- 先出现透明细线。
- 0.3 秒后增加亮度。
- 0.8—1.2 秒后产生攻击。
- 预警线不能与背景纹理使用同一亮度。

### 8.5 紫色梦尘泡泡

- 轮廓：圆形或不规则泡泡。
- 内部：慢速旋转的紫色颗粒。
- 吸收后：进入角色附近并消散。
- 不能伪装成敌方攻击。

## 9. 梦境演奏特效

### 9.1 时间回声

- 画面边缘出现缓慢旋转的时钟环。
- 弹幕拖尾拉长。
- 音符和粒子移动速度降低。
- 画面整体颜色偏蓝紫。

### 9.2 旋律反射

- 弹幕转化瞬间出现音符图案。
- 音符沿旋律线飞向敌人。
- 玩家周围出现三圈共振波。
- 背景加入轻微五线谱线条。

### 9.3 重力倒置

- 粒子向上飘散。
- 纸张、灯笼和小装饰向上翻转。
- 弹幕轨迹出现垂直方向残影。
- 镜头最多倾斜 5 度，避免影响可玩性。

### 9.4 梦境静止

- 普通敌人变成透明剪影。
- 弱点变为白色小核心。
- 场景背景停止滚动 0.3 秒后再恢复。
- 结束时敌人碎成紫色梦尘。

## 10. UI美术规范

整体方向：

- Q版图标。
- 圆角面板。
- 软边描边。
- 半透明深蓝背景。
- 青色、金色、珊瑚色作为功能色。
- 不使用大面积纯黑面板。

功能色：

- 玩家生命：珊瑚红。
- 共振：金色。
- 可切弹：青蓝。
- 可弹反：金色。
- 预警：白色。
- 梦尘：紫色。
- 普通信息：淡蓝。

UI字体：

- 中文标题：圆润、粗体、较大字面。
- 中文正文：清晰、笔画不要太细。
- 数字：易读的半粗字体。
- 重要数值不使用装饰性字体。
- 正文最小字号建议 12—14 像素。

HUD必须包含：

- 生命值。
- 共振值。
- 当前武器图标。
- 闪避充能。
- 当前波数。
- Boss生命值或当前阶段。
- 暂停入口。

## 11. 动画规范

主角至少制作：

- 待机。
- 移动。
- 射击。
- 切弹。
- 弹反。
- 闪避。
- 受伤。
- 濒死。
- 梦境演奏。
- 通关。

建议帧数：

| 动画 | 建议帧数 | 说明 |
|---|---:|---|
| 待机 | 8—12 | 梦灯轻微上下浮动 |
| 移动 | 8—12 | 身体向移动方向倾斜 |
| 射击 | 4—6 | 梦灯快速闪亮 |
| 切弹 | 6—8 | 弧形刀光和身体前倾 |
| 弹反 | 8—10 | 瞬间展开圆形护盾 |
| 闪避 | 6—8 | 留下梦灯残影 |
| 受伤 | 4—6 | 短促后退和灯光变红 |
| 演奏 | 12—18 | 旋律环绕和梦灯展开 |

动画原则：

- 攻击前摇比攻击本体更重要。
- 受击动画不能改变碰撞位置。
- Boss阶段变化不能完全遮挡战场。
- 动画夸张但要保证读得清。
- 重要操作采用 2—4 帧的强烈关键姿势。

## 12. 镜头与构图

横版战斗画面：

- 主角通常位于画面左侧 25%—35% 区域。
- Boss通常位于画面右侧 65%—80% 区域。
- 中央区域保留弹幕运动空间。
- UI不能遮挡主角碰撞区域。

Boss构图：

- Boss不能贴近画面边缘导致轮廓被裁切。
- Boss攻击方向需要通过身体朝向提前表达。
- Boss弱点放在视觉中心附近，但不能覆盖弹幕。

宣传图构图：

- 保留主角完整剪影。
- 保留Boss完整轮廓。
- 保留一条明确的弹幕或音符运动方向。
- 标题区域留出空白。

## 13. 资源规格和命名

建议规格：

| 资源 | 画布建议 | 格式 |
|---|---:|---|
| 主角单帧 | 512×512 | PNG |
| 普通敌人 | 256×256 | PNG |
| Boss单帧 | 1024×1024 | PNG |
| 弹幕 | 128×128 | PNG |
| VFX序列帧 | 256×256或512×512 | PNG |
| HUD图标 | 128×128 | PNG |
| 场景远景 | 2048×1024 | PNG或压缩纹理 |
| 场景中景 | 2048×1024 | PNG或压缩纹理 |

Unity导入建议：

- 角色和敌人使用 SpriteRenderer。
- UI图标使用 Sprite Atlas。
- 弹幕使用对象池和统一材质。
- 发光层使用独立 Sprite 或 Shader。
- 远景和中景放入不同 Sorting Layer。
- 小图标关闭不必要的高质量过滤，避免模糊。

命名结构：

类型_对象_动作或用途_编号

## 14. 制作流程

### 阶段一：剪影

先用黑白剪影确认：

- 角色是否能区分。
- Boss是否有识别特征。
- 武器动作是否清晰。
- 弹幕形状是否不重复。

### 阶段二：黑白构图

确认：

- 主角、敌人、Boss位置。
- 视觉焦点。
- 安全区域。
- 弹幕运动路线。

### 阶段三：基础色

确认：

- 主角和背景对比。
- 弹幕和背景对比。
- Boss和弹幕是否冲突。
- UI是否可以读清。

### 阶段四：光效和纹理

最后再加入：

- 梦境雾。
- 发光。
- 粒子。
- 纸张纹理。
- 梦尘碎片。
- 水面反射。

不能在构图和颜色稳定前先堆光效。

## 15. 质量验收清单

### 角色

- [ ] 角色缩小后仍能识别。
- [ ] 主角梦灯在暗背景中可见。
- [ ] 动作方向明确。
- [ ] 受伤和弹反有不同姿势。
- [ ] 没有过多细小装饰。

### 敌人和 Boss

- [ ] 普通敌人和精英敌人轮廓不同。
- [ ] 攻击前摇清楚。
- [ ] 死亡效果不会遮挡其他弹幕。
- [ ] Boss每个阶段有明显变化。
- [ ] Boss有独立的情绪和视觉核心。

### 场景

- [ ] 背景不会压过弹幕。
- [ ] 前中后景层次清晰。
- [ ] 场景颜色和章节主题一致。
- [ ] 视差滚动不会造成晕动感。

### UI

- [ ] 手机小屏幕能看清生命和共振。
- [ ] 可切弹和可弹反有明显提示。
- [ ] 主按钮和次按钮层级明确。
- [ ] 字体没有挤压和重叠。
- [ ] 色弱模式仍然能识别弹幕类型。

### 战斗

- [ ] 背景和特效不会遮挡主角。
- [ ] 弹幕轮廓保持清晰。
- [ ] Boss预警比攻击提前出现。
- [ ] 演奏效果足够明显但不影响操作。
- [ ] 低特效模式仍然保留关键反馈。

## 16. 内部沟通用风格描述

Q版梦灯生物，2.5到3头身，圆润剪影，深蓝紫梦境背景，暖黄色梦灯，青色和粉色弹幕，纸张和水彩纹理，柔和边缘发光，轻微诡异但不恐怖，适合手机小屏幕阅读，手绘2D横版动作游戏。

## 17. 禁用方向

- 写实射击游戏风格。
- 纯黑红恐怖风。
- 细节密度过高的厚重角色。
- 所有角色都是圆脸白色球体，没有职业差异。
- 所有弹幕都使用圆形。
- UI只使用文字，没有图标和状态颜色。
- Boss只改变体型，不改变情绪表达和攻击规则。
- 背景使用与弹幕相同的高亮颜色。

## 18. 原创和版权要求

Q版、手绘、梦境、弹幕、发光和可爱属于风格和类型方向，但角色设计、具体轮廓、服装、台词、音乐、UI图标和关卡构图必须原创。

所有外部参考图在进入生产前需要登记来源。商业版本使用的角色、场景、字体、音效和音乐需要确认授权或采用原创资源。

## 19. 最终风格目标

玩家看到画面时，应当马上识别出：

1. 这是一个可爱的 Q 版梦境世界。
2. 这里的弹幕是可以理解和互动的。
3. 主角、敌人和 Boss 轮廓各自清楚。
4. 梦境演奏会让画面和规则发生变化。
5. 画面有温暖感，也有继续探索的神秘感。
