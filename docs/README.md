# 策划文档

这里是《梦潮：回声航线》到目前为止收到的全部策划文档，按收到顺序编号。文件内容都是原文；05 和 08 原本是直接贴在对话里的，只去掉了粘贴外壳，08 另外把 `<br/>` 排成了段落和小标题。

## 怎么读

- **冲突时以编号大的为准**：09 > 08 > 07 > 06 > 05 > 04 > 02 > 01。03 美术规范一直适用。
- **09 的两处说明**：09 里账户货币叫“星砂”，游戏里仍叫“星尘”（局内拾取的才叫星砂，50:1 折成星尘），数值照 09；09 写“先不做多人联机”，但联机已按用户 2026-10-01 的要求做好，保留。
- **只做 Steam**（2026-09-27 决定）：各文档里关于手机 / 触屏（Android、iOS）、付费、广告、战令、外观包售卖、章节付费解锁等商业化内容都不做。
- **文档写的是“要做什么”，代码是“现在是什么”**：已经实现的行为以代码为准，数据和代码位置见仓库根目录的 [README](../README.md)。
- **缺的文档**：v0.3、v0.5（《技能 Build 与第一章节奏深化策划》）和原版 v0.8 主文档没有收进来；v0.8 目前只有修改意见（08）。
- **原文里失效的链接**：指向 `D:/小游戏/...` 的链接是策划本机的路径；05、06 引用的配图 `assets/v06-plane-map.svg`、`assets/v07-growth-loop.svg` 也没有收到。为了保持原文不改，这些链接原样保留。
