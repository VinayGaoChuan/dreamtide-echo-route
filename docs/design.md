这是本游戏唯一的策划文档。改设计就是直接改这一份，不另建新文档，也不留旧版本文件。

- **版本**：v0.12。2026-10-06 由 docs/01–10 合并而成。
- **旧原文**：在 Git 提交 `ba27caf` 的 `docs/` 里，按需查阅。

## 怎么读这份文档

- **优先级**：用户裁定（§15）> 本文 > 旧原文。
- **联机是最高要求**：本文哪一节缺了联机怎么办，实现时自己补全，再回写到这里。
- **本文写两件事**：要做成什么样，和现在做到哪一步。
  - 已实现的行为以代码为准，代码入口见仓库根目录 README。
  - 文中数值是测试起点，以测量结果为准，见 §14。
- **标记**：
  - 【已做】：游戏里已经有。
  - 【未做】：规划了，还没做。
  - 【本轮】：本轮打磨要做或已改。

## 0. 一句话、玩家、幻想

**一句话**：Q 版梦境横版自动射击。只用移动和一个大招键：
- 对准敌人；
- 飞进奖励物件挑升级；
- 每局长出一套不同的武器；
- 救回伙伴，让家园改变下一局的地图；
- 2–4 人在线合作或对抗。

**写给谁**：
- 喜欢“越打越强、清屏很爽”的大众向射击玩家：吸血鬼幸存者、土豆兄弟这一类，加上横版 STG 的轻度玩家。
- 喜欢可爱画风、和朋友一起玩的玩家。
- 他们要的是三样东西：
  - 一局里看得见的变强；
  - 每局不一样的组合；
  - 短局，失败也有收获。

**幻想**：驾驶一架梦灯小飞机穿越失控的梦。你的飞行路线会唤醒地图：
- 点亮房子；
- 吹开风车；
- 炸开矿壁；
- 护送伙伴。

地图则帮你长出武器。

**核心循环**：
1. 出击；
2. 清怪，对准敌人；
3. 地图物件或精英核心触发升级仪式；
4. 二选一；
5. 新能力立刻用同一种敌人验证；
6. 下一个目标；
7. Boss；
8. 结算；
9. 回家园：救回的伙伴开放建筑，项目改变下一局；
10. 再出击。

**目标阶梯**：

| 时间尺度 | 玩家此刻想要什么 | 达成后揭示什么 |
|---|---|---|
| 几秒 | 打掉眼前这一排、碰到那个物件 | 物件变形开奖 |
| 一个目标（约 20–40 秒） | 顶栏的主目标：厚甲怪、编队、精英、追兵、惊喜、Boss | 优势窗口 + 下一个威胁的预告 |
| 一局（3–4 分钟） | 凑成目标流派的联动、打倒 Boss | 结算、救回的伙伴、下一关 |
| 几局 | 家园的下一个项目、下一架飞机 | 下一局地图真的变了 |
| 整个游戏 | 4 章 12 关、6 架飞机、5 名伙伴【多数未做】 | — |

## 1. 平台与操作

**平台**：
- 只做 Steam（Windows、macOS、Steam Deck）。
- 手机、触屏、付费、广告、战令、外观售卖都不做。
- 现阶段是网页版：自己的服务器转发联机。
- 之后打 PC 包，接 Steam 大厅和网络 API。

**操作**：
- 移动：WASD、方向键、左摇杆或鼠标拖动。按住专注键低速移动。
- 大招键：空格或手柄主按钮。选升级时，按大招键等于选推荐项。
- 暂停：Esc 或 Start。
- 联机时按 H 看规则卡。规则卡贴在远离自己飞机的半边屏幕上。
- 不加第二个攻击键。没有切弹、弹反、闪避、装备、背包。

**屏幕**：
- 世界逻辑高 720。宽度随窗口在 1152–1560 之间变化；联机时固定 1280。
- 竖长窗口会暂停，并提示拉宽。

## 2. 战斗基础【已做】

**主炮**：
- 自动开火，固定向右，单发直线，命中第一个敌人就消失。
- 伤害 10，每秒 8 发。
- 开局没有穿透、没有追踪、没有自动瞄准。这些能力只能在局内二选一获得，新一局清空。
- 分身和僚机同样朝前发射，只继承本局已经拿到的改造。

**敌人分层**：

| 层 | 是什么 | 怎么打 |
|---|---|---|
| 普通怪 | 8 血，一发就散 | 成片清理、连杀、充能 |
| 厚甲怪 | 总生命 60：45 点甲只吃 18% 子弹伤害，分三段开裂；15 点核心吃满伤害 | 单只 3–5 秒 |
| 厚甲编队 | 多只厚甲排成队列 | 考验清队能力 |
| 带队精英 | 举旗时打旗头水晶；它倒下，护卫就散 | 有明确的弱点窗口 |
| 精英 | 守望水母、裂纹闹钟、双瞳星鱼 | — |
| Boss | 见 §5 | — |

**敌人数值固定**：
- 同一关里敌人参数固定，只乘本关的 hpK。
- 不随玩家变强偷偷加血，也不按实时火力加血。
- 回打旧关应该明显更轻松。

**威胁要公平**：
- 不能在预告之前伤人。
  - 入场有预告：后方追兵沿可见弧线、上下钻出有影子、裂缝先扭曲背景。
  - 预告中的敌人还不能碰撞。
- 不能生成在玩家身上，也不能从屏幕外打人。
- 所有方向都留有可躲的空间。只靠基础直射也能解。

**生命与失败**：
- 用心数计生命。被击中后有约 1.4 秒无敌，有受击暗角，没有镜头震动。
- 单人生命归零就失败。联机规则见 §9。
- 漏过的普通怪只影响额外评分，不扣血。

## 3. 局内 Build

### 3.1 三个槽【已做】

| 槽 | 能力 | 规则 |
|---|---|---|
| 主炮改造 | 穿透、追踪、多重、爆破，各 3 级 | 互相兼容、累积 |
| 自动支援 | 雷球、分身、彩虹光束、冰晶、磁吸星砂，各 3 级 | 同时只带一个；换新的先展示前后对比 |
| 大招改造 | 雷霆、冰封、连爆、星砂回收，各 2 级 | 同时一个 |
| 联动 | 两件前置都到 2 级时自动接上（第一局的第一个只要 1 级），不再单独占一次选择；一局只接一个（第一个凑齐的，§3.9），两件都到 3 级再乘 1.5 | 见下表 |

**联动表**：

| 联动 | 前置 | 效果 |
|---|---|---|
| 贯穿终点爆炸 | 穿透 + 爆破 | 穿透子弹最后一下炸开 |
| 蜂群同步开火 | 追踪 + 分身 | 分身跟着主炮开火，子弹追踪 |
| 追踪雷链 | 追踪 + 雷球 | 追踪弹命中时放电 |
| 散射冰晶 | 多重 + 冰晶 | 侧翼子弹冻住敌人 |
| 雷爆连锁 | 爆破 + 雷球 | 雷击标记，爆炸再放电 |
| 彩虹烟火 | 爆破 + 彩虹 | 爆炸变成彩色烟火 |
| 星砂散射 | 多重 + 磁吸 | 吸到星砂就射出星弹 |

**流派**（`BUILD_PATHS`）：每个流派 = 两件组件 + 一个联动。共 7 条：
- 贯穿爆破
- 追踪蜂群
- 追踪雷暴
- 散射冰晶
- 烟火
- 雷爆
- 星砂散射

大厅的“下一局目标”、暂停页、结算页、升级卡片上的“★目标流派”，都读同一个来源（`buildPlan`）。

**奖励池规则**：
- 第一次固定是穿透 1 / 追踪 1。
- 第二次：一个已有方向的升级 + 一个兼容的新方向。
- 第三次保证至少一个能联动。
- 连续两次没有能升级的项，就强制给升级。
- 满级、无效、缺前置的项不进候选。
- 第一只厚甲怪之后：一个“集中打单体”的方案 + 一个“清一片”的方案。

### 3.2 测量（`node tools/report-sim.js js 4`）

测量方法：机器人按 7 个流派各追一遍，打 1-1、1-2、1-3，共 84 局。
- “基线”：2026-10-06 打磨前。
- “打磨后”：同一天本轮改完。基线之后机器人学会了躲白线，所以 1-3 胜率不能直接比，见 lessons TP7。

| 指标 | 基线 | 打磨后 | 目标 |
|---|---|---|---|
| 一直没拿到任何联动的局 | 41 / 84（49%） | 5 / 84（6%） | ≤ 1/3 |
| 第一个联动出现时间（中位） | 115 秒 | 99 秒 | 越早越好；策划原定 ≤ 60 秒，受开局几个装置的位置限制 |
| 追到自己目标流派联动的比例 | 8–42% | 25–100%：三条 100%，其余 25–67%。机器人会拿别的流派先到的联动 | 玩家能把一局引向自己想要的流派 |
| 只加数字的选择 | 10% | 10% | ≤ 50% |
| 局与局重合度 | 0.30 | 0.32 | ≤ 0.6 |
| 各流派胜率 | 75–92% | 75–100% | 差 ≤ 25 个百分点 |
| 总胜率（推荐等级） | 85%（1-3 54%） | 92%（1-3 86%） | 第一章终点不设成长墙 |

**结论**：
- 打磨前：选择本身不是只加数字；问题在于随机决定了流派能不能成，玩家没法引导，一半的局到 Boss 都没成型。
- 打磨后：几乎每局都能凑成联动，玩家也能把一局引向自己想要的流派。

### 3.3 Build 方案【本轮已做】

**流派引导**（`aimPlan`）：每一局都有一条“正在追的流派”。
- 单人：大厅设了目标流派，并且你还没走到别的流派上，就追大厅的目标。
- 其他情况：追离当前 Build 最近、还没做完的那条。
- 联机：只看自己的 Build，各端一致。

**候选怎么出**（第一次固定是穿透 / 追踪，从第二次起按下面的顺序）：
1. 六成的时候，一张卡给本局流派的下一步（这个装置的池子里有的话）：先把联动的两件各拿到，再各升到 2 级，最后是流派的其他件；另一张照常随机。另外四成两张都随机。会规划的人照样成型，随手拿的人难得凑齐（§3.5）。
2. 第二次选择：一张是已有方向的升级，一张是新方向。
3. 第一只厚甲之后的“集中 / 清一片”二选一，优先给本局流派缺的那一件。
4. 两件到级的那一下，联动自动接上，那次仪式就是“组合完成”。

**卡片和推荐**：
- 卡片上的“★目标流派”和大招键的推荐读同一个计划。
- 推荐顺序：目标流派件 > 能凑联动的件 > 升级。

**改造写在子弹上**（每一发都看得见 Build）：

| 改造 | 子弹上的样子 | 满级 |
|---|---|---|
| 穿透 | 金色长光轨，等级越高越长 | 白金光枪 |
| 追踪 | 沿真实飞行路线弯过去的青色尾迹 | 尾迹带星屑 |
| 爆破 | 橙色引信圈，越高级越大、闪得越快 | — |
| 多重 | 并排的几路 | — |

每发一次，炮口都会闪一下，颜色是最高级那项改造的颜色。

**验证编队来两波**：升级后用同类敌人验证，第二波 1.6 秒后来。新能力要有足够的东西打，力量感才落地。

### 3.4 升级仪式【已做】

完整仪式按九步走：
1. 触发（0.3 秒回应）；
2. 变形（房子折成转盘，核心展开成水晶轮）；
3. 滚动（先快后慢）；
4. 真实升品质：结构、颜色、声音都变，只升不降（品质见下）；
5. 揭晓；
6. 二选一：飞进候选圈，停 0.3 秒确认；单人不限时；
7. 中央展示；
8. 飞进真实槽位；
9. 验证编队。

**奖励焦点**：
- 从变形到入槽，战场以 0.1 倍速运行，并且去饱和、变安静。
- 飞机稳住，有护盾；不刷怪，不发起新攻击。
- 关卡计时、连杀和冷却都暂停。
- 入槽后有 0.8 秒保护过渡。

**品质**（2026-10-06 改）：完整仪式掷一档，普通 → 史诗 → 传说 → 神话，每升一档转盘上演一次（颜色、光圈、“品质提升 · 传说”）。
- 玩家一档一档认识品质（`QUALITY_ROLL`）：
  - 史诗从第一局就常见（每次完整仪式约一半）；
  - 传说从共享等级 2 级起出现，神话从 8 级起少量出现，之后都随等级涨。
  - 开局人人拿普通、偶尔史诗时，一件史诗就让人珍惜；神话一上来就给，玩家感受不到它的分量。
  - 装置自带保底（梦灯屋、精英核心、断桥史诗起，巨鲸、月亮传说起），但 7 级前最多保到史诗。
- 相邻两档拉开一眼看得出的差距：颜色（白、紫、金、粉红）、转盘多亮一圈、仪式更重；对路时的火力倍率见下。
- 品质不加等级。只有对路的件（属于已成型流派的两件、流派的其他件、联动本身）才把品质乘到全部火力上：史诗 ×1.3，传说 ×1.7，神话 ×2.5。
- 所以给了不等于强：打穿要靠对路（和这局的构筑有关）、凑齐（三件以上对路的高品质件）、选对（二选一别搭错）。随手拿的人拿到的件一样多，强度却上不去。
- 卡片上说清楚：对路的高品质卡多一个“对路”箭头；不对路的写一行“史诗好看，但不是本局流派的件”（能和已有的件凑联动的，照旧提示能凑联动）。

**仪式长短**：
- 首个重要强化、第一次联动、高品质奖励用完整仪式，每局 2–3 次。
- 重复升级用短仪式。
- 资源掉落直接吸入。

**数据与表现**：确认选择的那一刻就写入数据；飞入只是表现。中途退出或重连只补展示，不重抽，不重复发。

### 3.5 难度和构筑挂钩【已做，2026-10-06】

用户裁定（§15）：胜率太高了，难度要结合能不能 build 出来；给和强是两回事；难度跟着玩家玩了多久变。肉鸽的承诺是“我赢，是因为我搭出了一套好构筑”，所以难度看构筑强度和胜负的关系，不看一个总胜率。

**构筑强度**（`report-sim` 每局的 `strength`）：首领战有一个确定的期限 T（超载的时刻），强度 = T ÷ 按这一局的净进度（打掉的生命 − 自愈回来的）打完首领要多久。
- 1 = 正好在超载那一刻打完；2 = 一半时间就打完。
- 所有东西都汇进这一个数：几件主炮改造、支援、联动、对路的高品质件、局外等级。
- “成型”是这条线上的一个刻度：联动的两件都到 2 级，联动自动接上。

**规则**（数值在 `data.js` 的 `BUILD_CHECK`、`QUALITY_*`）：
- 联动：两件都到 2 级自动接上，不再单独占一次选择（第一局的第一个只要 1 级）；一局只接第一个（§3.9）。
- 成型那一刻所有攻击 × 倍率（飘字“成型！火力大涨”）；两件都升到 3 级再 × 1.5。每个联动倍率不同，按连打时第二、第三个首领上各流派的强度拉平（`formKOf`）：贯穿终点爆炸 1.45、彩虹烟火 3.33、追踪雷链 3.95（追踪弹容易被首领的散兵引走）、雷爆连锁 3.9、蜂群同步开火 2.9、星砂散射 3.0、散射冰晶 2.8。
- 对路的高品质件再乘上去（§3.4 品质）。
- 多重扫得更宽，但打同一个大目标时总伤害是 1 / 1.45 / 1.8 / 2.1 倍，不再能一路叠多重顶替成型。
- 引导六成的时候出现（§3.3）。
- 首领是构筑考验（第一个首领除外，§3.6）：
  - 自愈：每秒回 0.3% 最大生命，散兵或护盾护着时不回；血条发绿光。
  - 失控：打了一定时间还没倒，攻击一路加快（每 15 秒快一倍，最多 5 倍），血条上提前 15 秒倒数，失控后一圈红色虚线。
  - 超载：失控 35 秒后全屏冲击、全队倒下，血条上倒数，提前 5 秒喊。首领战一定有个结局，强度按它算。
  - 失控时间：1-1 40 秒、1-2 70 秒、1-3 55 秒；超载再加 35 秒。
  - 首领加厚：1-1 1.3、1-2 7.5、1-3 15 倍。三关连成一局后按“这一局走到那里时构筑通常有多强”定，参照玩家第一次走到那里时的等级（§3.9）。
- 失败复盘提示：“首领打太久会失控，再拖就超载……”。对抗模式不受这些影响。

**怎么量**：
- 难度：`node tools/report-sim.js js 25 --human --archetypes all,random,rec --jobs 9`。
  - `--human`：机器人按普通玩家，威胁出现 0.25 秒后才反应，每半秒 12% 走神，瞄准偏 14 像素以内，会躲迎面的敌人。
  - 7 个流派各跑一遍，加上 `random`（随手拿、从不规划）和 `rec`（总按推荐、按大招键的人）。
  - `--lv N` 指定共享等级，`--ladder N` 指定梦魇级。
- 连续玩：`--career N`，见 §7。
- 报告的“难度”一节给出强度分布、按强度分档的胜率、各流派强度中位、打穿的比例、高品质件（每局几件、第一件在第几秒）、按对路件分档的强度。

### 3.9 三关连成一局【已做，2026-10-07】

用户裁定（§15）：三关连成一局，构筑带着走；先别往大里扩（不加梦魇级、不做第二章）；第一次通关不能靠碰运气。

**为什么**：原来一关一局、构筑每局从零开始，1-3 又按一个固定的建议等级定难度。玩家到了 1-3 只能拿一套刚搭的小构筑去撞满强度的首领，首通靠反复试十几次、偶尔中一次。连成一局后构筑一路长大，三个首领按“这一局走到那里时，认真搭的构筑通常有多强”定难度。

**规则**（`World.advanceStage`、`BUILD_CHECK`）：
- 一局从 1-1 打起，首领倒下后原地进下一关：横幅“第 N 关 · 名字”，天色和音乐换掉；打倒 1-3 的首领才算整章通关。
- 带着走：飞机、构筑（主炮、支援、大招改造、联动、品质）、心数、资源、统计、随行伙伴。换新：敌人、地图物件、目标链、首领。
- 每过一关回两颗心，倒下的队友站起来。
- 一局只接一个联动：第一个凑齐的。对路件只算这条流派路线上的件；联动的两件都到 3 级，火力再 × 1.5（`maxK`）。
  - 原因：连打时一局有十八九次选择，随手拿也会凑出四五个联动，件件都算对路，认真搭和随手拿的差别就没了。
- 第 2、3 关的普通战斗加压（`CHAIN_FOE`，2026-10-07）：普通敌人（含厚甲、精英、地图伸手）生命 1-2 ×8、1-3 ×20，背景杂兵 ×1.3、×1.6；首领战另按 `bossK`。
  - 原因：带过来的构筑比从零开始强得多，不加压时一关比一关轻松——平均击破用时 1.03 → 0.52 → 0.33 秒，1-3 普通战斗的压力只有 1-1 的四分之一，最长平静 35 秒。
  - 量法：第 2、3 关的击破用时回到第 1 关的水平。加压后 0.9 秒左右，普通战斗强度 4 → 4.5 → 6（1 级）；一局三关约 12 分钟。生命要加这么多，是因为成型构筑打杂兵时大部分伤害都溢出了。
- 结算：打倒的每个首领各算一份首通或再通关奖励（星尘、招募券、外观票）；整章通关才解锁梦魇（现在收起来了，§3.7）。
- 大厅的关卡条只显示进度（亮的是还没打倒首领的最前一关），出击按钮是“第 1 章（三关连打）”。
- 联机合作同样连打（§9）；对抗不变。

**目标怎么来的**（梦潮自己的量；数字在 §14 的 `report-targets`，`report-sim` 读它）：

梦潮自己的量：
- 一关 3–4 分钟，一局三关 12–15 分钟；倒在第二个首领约 8 分钟。加菜单约 1 分钟，每小时 4–6 局。
- 一局约 18–20 次选择、8–9 次完整仪式；有计划时第 5 次选择左右成型，也就是 1-1 后段或 1-2 前段。
- 首领期限 T：1-2 105 秒、1-3 90 秒（1-1 不考）。
- 参照等级不是固定的建议等级，而是玩家第一次走到那个首领时实际的共享等级（`--career` 量）。第一局就能走到第二个首领，所以它的参照等级是 1 级。

推出来的目标：
1. 第一个首领几乎人人过：有计划、照推荐、随手拿都 ≥ 90%。基础难度下不自愈、不失控、不超载（§3.6）。
2. 第二个首领考构筑（参照 1 级）：成型的构筑在 1 级时有一搏，随等级上去越来越稳；不成型的多半不能。
   - 有计划、照推荐 25–60%，随手拿 ≤ 25%。
   - 第一局（还在学的新手）多半倒在这里：这正是“过了第一个首领再输”的第一局。玩家约半小时第一次打过它。
3. 最后一个首领考成型的构筑和操作（参照第一次走到它的等级，约 3 级）。
   - 首通不早于两小时：玩家约 0.6 小时第一次走到这里，到两小时约见它 7 次，平均每次约 10%。所以第一次走到时有计划、照推荐 ≤ 15%（多半还打不过），之后靠局外成长和学会搭构筑往上爬；往上爬由连续玩的“胜率随尝试次数”量（§7）。
   - 认真搭和随手拿的差距按整章通关量：在玩家首通时的等级（约 7 级）上，随手拿的整章通关率不超过有计划的 60%。走到最后一关的随手拿是幸存者（恰好早早成型），一局十七八次选择又够把所有槽升满，只看最后一个首领会看走眼。
4. 每一段都是挣来的（用户 2026-10-07：「每章难度增加，给玩家的挑战越来越大」）：
   - 一段比一段难：玩家打倒每个首领之前（含那一场）的胜率一段比一段低；在玩家第一次走到每一段时的等级上，普通战斗的压力也一关比一关高（等级再上去，打过的前段越来越轻松是应该的）。
   - 第一次打倒第 2、3 段的首领，那一场的强度中位 ≥ 1，不到 1 倍的不过半（DE28）；
   - 胜率随尝试次数爬上去：第 3 次以后至少是第 1 次的两倍（局外成长 + 学会搭构筑）。
5. 认真搭和随手拿的差距保住：不靠整体降难度。

结果见 §3.8。

用户裁定（§15）：横版通关没有特色就太传统；地图要会出手，要有先兆，能摧毁，给奖励；出怪方向要跟着节奏和压力变。

**L1 判断**：
- 这让一张静帧就能看出本作的特色：海里伸出来的手、醒来扑咬的灯笼、往里合拢的纸页。
- 抬的是 G6 差异化、G2 五秒购买理由、G5 传播性，不压低任何一项。
- 它碰到了商店钩子，所以改完要在新截图上重跑 L1。

**会出手的地图**（`mapfx.js` 的 lurk）：

| 关 | 边缘伸手 | 装饰醒来 | 地形合拢 |
|---|---|---|---|
| 1-1 梦灯海湾 | 潮汐之手：从下方海里伸出 | 咬人灯笼：顶上灯串里的一盏 | — |
| 1-2 纸船灯河 | 折纸手：从上方伸下 | 纸船怪：河上的一只纸船 | 折页合拢：上下纸页往里折 |
| 1-3 失眠钟塔 | 发条手：从上方伸下 | 钟面怪：背景里的一个小钟 | 齿轮墙：上下齿轮墙往里压 |

**危险语言**（三种共用一套，一眼和友方的青白色分开）：
- 统一的危险色（粉红 `HAZ`）：先兆的柱子、虚线、箭头，手臂和墙的描边，封印的光都是这个颜色；
- 来源那一侧的屏幕边缘闪“！”（装饰醒来时“！”挂在它头上，不压住脸）；
- 出手的东西长成敌人的样子：手掌有爪、红瞳孔、皱眉；醒来的装饰睁眼长牙。

**先兆**：每种固定、每次一样，先兆期间碰不到人。
- 伸手（1.1 秒）：
  - 手从飞机**前方**伸出（这样只向右开火的飞机打得到它），伸到飞机当时的高度；
  - 那一列出现危险色的柱子和虚线框，标出手会伸到哪里；一条向左的虚线箭头标出它会往飞机这边横扫；
  - 边缘按主题冒泡、起皱或齿轮转，指尖探出来抽动，每种有自己的声音。
- 装饰醒来（1.0 秒）：装饰放大到 1.6 倍、抖动、发危险色的光、慢慢睁眼，同时画出扑咬方向的危险色虚线箭头（和敌人路线的白虚线分开）。
- 合拢（1.3 秒）：上下边缘起危险色折痕，伴随轰响。

**反制和奖励**：
- 伸手：
  - 离开那一列 / 那条高度就躲开；
  - 伸出来后用 0.45 秒往左横扫、握住 1.2 秒，再缩回；这段时间可以打碎（生命 70 × 本关系数）；
  - 打碎：6 颗大星砂（共 18）+ 每人大招充一截。
- 装饰醒来：
  - 扑出去 0.75 秒（沿着箭头）→ 悬停 2.6 秒（可打）→ 逃走；
  - 打掉：同样的奖励。
- 合拢：
  - 上下各往里压 92 像素，持续 6 秒，0.6 秒折进来、0.8 秒退回去；
  - 墙上两个封印（危险色的星结，外面一圈跳动的光），都打碎就马上撕开退回，再给 1.5 倍奖励；
  - 墙本身不伤人，只是压缩空间。
- 结果看得见：
  - 挨打：显出血条，裂纹随伤势变多；
  - 打碎：原地弹出“+18 星砂”和一圈光，星砂飞向飞机；
  - 躲过（这一下没伤到任何人）：飞机旁“躲开了！”和一圈闪光。
- 公平：攻击部件出现时，“出现时间”从先兆开始算，不会算作不公平受击。

**出场节奏**：
- 第一次出现在平静段当教学：横幅一句话讲先兆和反制。
- 之后只在高潮段出现，同一时间最多一个，间隔至少 14 秒。
- Boss 战不出，开打时收掉。

**出怪方向跟着压力**（`director.js` 的 `tension` / `directSides`）：
- 每个目标自己走一轮压力：
  1. 平静：目标刚开始；
  2. 蓄压：鱼群潮前 5 秒；
  3. 高潮：鱼群潮后 7 秒；
  4. 回到平静。
- 优势窗口、预告、拿奖励的时候算喘息。

| 阶段 | 从哪里来 |
|---|---|
| 平静 | 只从前方 |
| 蓄压 | 前方 + 固定的一侧，带预告：上方云影 / 下方海面鼓起各 1 秒，后方左边缘红影 1.3 秒 |
| 高潮 | 鱼群潮从前方；侧面小队每 2.6 秒换一个已开的方向；加地图出手 |
| 喘息 | 只从前方 |
| Boss 战 | 打了 12 秒或血掉到八成以下后，每 7 秒从已开的侧面来一小队 |

- 一开始只有前方。从第二个目标起，每个目标在平静时开一个新方向或一种地图元素，一次只开一个。各关的开放顺序：

| 关 | 开放顺序 |
|---|---|
| 1-1 | 下方（潮汐之手）→ 场景（咬人灯笼）→ 上方 → 后方 |
| 1-2 | 场景（纸船怪）→ 场景（折页合拢）→ 上方（折纸手）→ 下方 → 后方 |
| 1-3 | 上方（发条手）→ 场景（钟面怪）→ 场景（齿轮墙）→ 后方 → 下方 |

- 侧面小队是 3–4 只一发就散的水母或蛾子。
- 测量：`World.pacing().sides` = 最近 4 秒威胁来自几个方向，Boss 一直算前方。节奏报告同时按强度三等分和按压力阶段给出方向数。
- 结果（`node tools/report-sim.js js 4`，84 局，2026-10-06）：
  - 改前：出怪没有方向规则，几乎都从右边来，地图不会出手；
  - 改后出怪方向数：平静 1.31、蓄压 1.83、高潮 1.84、喘息 1.20、Boss 1.40，最多 4 个方向；
  - 地图出手：每局打碎 4.3 次，84 局里打中玩家 31 次，不公平受击 0；
  - 每局受击 3.4 → 4.6 次（多出来的主要是侧面小队的接触），胜率 98%，输局没有聚集；
  - L1 预测 0.14（校准 0.077），和改前持平；新鲜评审第 5 轮 ready（0 核心问题）。

- 反馈强弱跟时刻的稀有度和重要性一致。

## 7. 局外成长【第一阶段已做；2026-10-06 改成小步多升】

用户裁定（§15）：局外成长是标配，要有感知；共享等级加攻击和心数保留；解锁是第二条线。

**每局带出什么**（输了也有，走得越远越多）：
- 每完成一个目标当场入账一份星尘；捡到的星砂按 50:1 折成星尘；梦木；救出的伙伴；
- 通关另给终点奖励（首通更多），梦魇级数越高星尘越多。

**下一局开局看得见的变强**：
- 共享等级 1–20 级，所有飞机一起变强：攻击 ×1.035^(等级−1)，第 4、8、12、16、20 级各多一颗心。
- 费用 150 起，10 级前每级 +60，之后每级 +180：前期一两局升一级，后期越来越慢，满级要十个多小时。
  - 2026-10-07 三关连成一局后乘了 1.5：连打一局 8–12 分钟、带回的星尘约是原来一关一局的两倍，按原价每小时升级快一倍，首通会提前到一个半小时（§3.8）。
- 每升一级给 1 个天赋点。

**解锁线**（第二条线，不代替变强）：下一关、梦魇级（§3.7）、大招容量、家园建筑、伙伴、图鉴。

**和难度怎么配合**：
- 打过的内容越来越爽：满级时随手拿也能轻松打过基础 1-3。
- 新内容按带着局外成长的力量定难度：三个首领按“连打走到那里时构筑通常有多强”定，参照玩家第一次走到那里时的等级（§3.9），梦魇按满级 20 级；在玩家的前沿上仍然是构筑决定胜负。
- 品质也随等级涨：等级越高，传说、神话越常见（§3.4）。

**通关后追什么**：梦魇 1–5、家园、图鉴。更长线（几十小时）要靠第二章，见 §12。

**连续玩的模拟**（`node tools/report-sim.js js --career 24 --human --jobs 9`）：
- 一群玩家从新存档开始，带着局外成长连续打，每人最多 120 局或 20 小时，每局另算 60 秒菜单和家园时间。
- 打法：每局从 1-1 连打（§3.9）；梦魇收起后（§3.7）首通以后继续打普通难度；照推荐选；星尘够就升级，天赋点按推荐点亮。
- 只有第一局按“地图装置都没见过”教一遍，之后的局都见过（和真实存档一样）。
- 玩家在学：头 2.5 小时从新手（反应 0.45 秒、常走神、常随手拿）长到普通玩家。
- 报每个里程碑在第几小时、第一局打过首领的比例、有没有白打的局、下一局开局是不是更强、最长多少局没有新东西、高品质件前五局和最后五局各几件；
  还报第一次走到每个首领时的等级（各首领的参照等级）、首通那一局最后一个首领的强度、最后一个首领的胜率随尝试次数怎么变。
- 目标（从梦潮自己的量推出来）：
  - 第一局打过第一个首领 ≥ 90%：1-1 首领不考构筑、多两颗心，输只因躲不开。

  - 首通之前（梦魇开着时是打完最高一级之前），连续没有新东西不超过 10 局（约一小时）。前期一两局升一级，后期五六局一级。
  - 每一段都是挣来的：见 §3.9 第 4 条，报告按段给出第一次走到 / 打倒时的等级和时间、打倒那一场的强度、胜率随尝试次数。

## 9. 联机（2–4 人）

**同步方式**：用户裁定，只同步操作，确定性模拟。
- 每秒 30 个操作帧，每帧 4 个模拟步（120 Hz）。
- 每帧 5 个字符，每 30 帧比对一次状态哈希。
- 转发：现在用自己的服务器（`server/relay.js`），之后接 Steam。

**合作**【已做】：
- 和单人一样三关连成一局（§3.9），从 1-1 打起；房间不再选关，梦魇级用房主选的。换关在模拟里发生，各端一致，重连追帧也能追过换关。
- 各拿各的：每人自己的 Build、升级、掉落、资源。
- 全队统一进入升级：选好的人等队友。限时 25 秒，到时自动选推荐。
- 击毁救援：
  - 队友飞进宽救援圈停约 2 秒，就地救起；
  - 回约 40% 生命，有 2 秒保护；
  - 不自动复活；救援圈里的敌弹会化掉；
  - 在线的人全部倒下才算失败。
- 房主断线，其余人继续。
- 断线保留席位 60 秒：断线中原地占位，回来后按操作记录追上；超时才移除，主动退出直接移除。
- 刷新页面能回到原对局。
- 房间有准备确认和 3 秒倒计时。
- 同一局只结算一次（奖励账本）。

**对抗**【已做，自由竞争 2–4 人】：
- 每人一条航道。三段，每段 120 秒，计时在升级时暂停。
- 每段的节奏：
  - 风塔目标分；
  - 干扰洞口（矿甲列阵或侧风，每段一次，排队不叠加）；
  - 冲突区直接对攻。
- 被击毁后 3 秒原地复归。
- 以目标分为主。
- 可以选“统一属性”。
- 结算拆解每一项得分。

**未做**：

- 公共匹配、Steam 好友与大厅；
- 进入他人家园与权限；

- 快捷沟通（标记、求救、等我、感谢）；

## 10. 美术方向（Q 版规范，一直适用）

**情绪比例**：可爱 60%、梦幻 25%、轻微诡异 15%。

**画法**：
- Q 版手绘 2D：圆润轮廓、大色块、软边发光、纸张纹理、漂浮物。
- 现在全部是 Canvas 程序绘制。

**线与光**：
- 线条用深蓝紫，不用纯黑。外轮廓比内线粗。
- 主光来自上后方的月光或梦灯。

**颜色**：
- 主角暖白和金黄梦灯；能量青紫；受伤珊瑚红。
- 背景不能比战斗元素更亮，不能用弹幕的高亮色。
- 弹幕靠形状、速度和颜色共同区分：
  - 粉色圆弹；
  - 蓝色菱形；
  - 金色星弹；
  - 白色预警线：先出现透明细线，0.3 秒后变亮，0.8–1.2 秒后攻击。

**造型**：
- 精英不能只是普通怪放大换色，要多一个识别元素。
- Boss 占画面横向 20–35%，每个阶段有明显变化。

**构图**：主角在左侧 25–35%，Boss 在右侧 65–80%，中间留给弹幕。

**禁用方向**：
- 写实射击风；
- 纯黑红恐怖风；
- 所有角色都是白色圆球；
- 所有弹幕都是圆形；
- UI 只有文字。

**原创**：角色、轮廓、音乐、图标、关卡构图全部原创。

## 11. 文字与界面

**文字规则**：用户裁定，见 §15。
- 机制和技能说明一律写成：图标 + 名字，换行一句话，不写数值。
- 强弱用箭头表示：绿 ▲、红 ▼，1–3 个。
- 显示的数字必须等于实际用的数字。

**屏幕上的信息**：
- 顶栏只显示一个主目标，外加一个可选的地图目标。
- 屏幕中央留给战斗；过期的标题卡要替换或淡出。

**按钮**（用户裁定 2026-10-07，§15）：每个按钮要么按下有看得见的结果，要么灰着、按下说出原因；被面板盖住的按钮不能看起来还能点。
- 灰着的按钮用 `offIf(条件, 原因)`：仍能按，按下弹出原因（不用 `disabled`：禁用的按钮按了什么都不发生）。
- 点已经选中的东西：原地闪一下（`pulse`）。
- 只是进度、不能选的东西不做成按钮（大厅的关卡条）。
- `node tools/ui-check.js`：无头 Chrome 逐个界面按每个按钮，0.6 秒内画面没变化报“死按钮”，按钮中心点到别的东西报“被盖住”，滚不进来的报“出了屏幕”。2026-10-07 修掉 16 处（§3.8）。

### 11.1 战斗界面：用时飞入，暂停全来【已做，2026-10-07】
