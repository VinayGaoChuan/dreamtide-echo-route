# 梦潮：回声航线 · 设计文档

这是本游戏唯一的策划文档。改设计就是直接改这一份，不另建新文档，也不留旧版本文件。

- **版本**：v0.12。2026-10-06 由 docs/01–10 合并而成。
- **旧原文**：在 Git 提交 `ba27caf` 的 `docs/` 里，按需查阅。

## 怎么读这份文档

- **优先级**：用户裁定（§15）> 本文 > 旧原文。
- **联机是最高要求**：本文哪一节缺了联机怎么办，实现时自己补全，再回写到这里。
- **本文写两件事**：要做成什么样，和现在做到哪一步。
  - 已实现的行为以代码为准，代码入口见仓库根目录 README。
  - 文中数值是测试起点，以测量结果为准，见 §14。
- **标记**：
  - 【已做】：游戏里已经有。
  - 【未做】：规划了，还没做。
  - 【本轮】：本轮打磨要做或已改。

## 0. 一句话、玩家、幻想

**一句话**：Q 版梦境横版自动射击。只用移动和一个大招键：
- 对准敌人；
- 飞进奖励物件挑升级；
- 每局长出一套不同的武器；
- 救回伙伴，让家园改变下一局的地图；
- 2–4 人在线合作或对抗。

**写给谁**：
- 喜欢“越打越强、清屏很爽”的大众向射击玩家：吸血鬼幸存者、土豆兄弟这一类，加上横版 STG 的轻度玩家。
- 喜欢可爱画风、和朋友一起玩的玩家。
- 他们要的是三样东西：
  - 一局里看得见的变强；
  - 每局不一样的组合；
  - 短局，失败也有收获。

**幻想**：驾驶一架梦灯小飞机穿越失控的梦。你的飞行路线会唤醒地图：
- 点亮房子；
- 吹开风车；
- 炸开矿壁；
- 护送伙伴。

地图则帮你长出武器。

**核心循环**：
1. 出击；
2. 清怪，对准敌人；
3. 地图物件或精英核心触发升级仪式；
4. 二选一；
5. 新能力立刻用同一种敌人验证；
6. 下一个目标；
7. Boss；
8. 结算；
9. 回家园：救回的伙伴开放建筑，项目改变下一局；
10. 再出击。

**目标阶梯**：

| 时间尺度 | 玩家此刻想要什么 | 达成后揭示什么 |
|---|---|---|
| 几秒 | 打掉眼前这一排、碰到那个物件 | 物件变形开奖 |
| 一个目标（约 20–40 秒） | 顶栏的主目标：厚甲怪、编队、精英、追兵、惊喜、Boss | 优势窗口 + 下一个威胁的预告 |
| 一局（3–4 分钟） | 凑成目标流派的联动、打倒 Boss | 结算、救回的伙伴、下一关 |
| 几局 | 家园的下一个项目、下一架飞机 | 下一局地图真的变了 |
| 整个游戏 | 4 章 12 关、6 架飞机、5 名伙伴【多数未做】 | — |

## 1. 平台与操作

**平台**：
- 只做 Steam（Windows、macOS、Steam Deck）。
- 手机、触屏、付费、广告、战令、外观售卖都不做。
- 现阶段是网页版：自己的服务器转发联机。
- 之后打 PC 包，接 Steam 大厅和网络 API。

**操作**：
- 移动：WASD、方向键、左摇杆或鼠标拖动。按住专注键低速移动。
- 大招键：空格或手柄主按钮。选升级时，按大招键等于选推荐项。
- 暂停：Esc 或 Start。
- 联机时按 H 看规则卡。规则卡贴在远离自己飞机的半边屏幕上。
- 不加第二个攻击键。没有切弹、弹反、闪避、装备、背包。

**屏幕**：
- 世界逻辑高 720。宽度随窗口在 1152–1560 之间变化；联机时固定 1280。
- 竖长窗口会暂停，并提示拉宽。

## 2. 战斗基础【已做】

**主炮**：
- 自动开火，固定向右，单发直线，命中第一个敌人就消失。
- 伤害 10，每秒 8 发。
- 开局没有穿透、没有追踪、没有自动瞄准。这些能力只能在局内二选一获得，新一局清空。
- 分身和僚机同样朝前发射，只继承本局已经拿到的改造。

**敌人分层**：

| 层 | 是什么 | 怎么打 |
|---|---|---|
| 普通怪 | 8 血，一发就散 | 成片清理、连杀、充能 |
| 厚甲怪 | 总生命 60：45 点甲只吃 18% 子弹伤害，分三段开裂；15 点核心吃满伤害 | 单只 3–5 秒 |
| 厚甲编队 | 多只厚甲排成队列 | 考验清队能力 |
| 带队精英 | 举旗时打旗头水晶；它倒下，护卫就散 | 有明确的弱点窗口 |
| 精英 | 守望水母、裂纹闹钟、双瞳星鱼 | — |
| Boss | 见 §5 | — |

**敌人数值固定**：
- 同一关里敌人参数固定，只乘本关的 hpK。
- 不随玩家变强偷偷加血，也不按实时火力加血。
- 回打旧关应该明显更轻松。

**威胁要公平**：
- 不能在预告之前伤人。
  - 入场有预告：后方追兵沿可见弧线、上下钻出有影子、裂缝先扭曲背景。
  - 预告中的敌人还不能碰撞。
- 不能生成在玩家身上，也不能从屏幕外打人。
- 所有方向都留有可躲的空间。只靠基础直射也能解。

**生命与失败**：
- 用心数计生命。被击中后有约 1.4 秒无敌，有受击暗角，没有镜头震动。
- 单人生命归零就失败。联机规则见 §9。
- 漏过的普通怪只影响额外评分，不扣血。

## 3. 局内 Build

### 3.1 三个槽【已做】

| 槽 | 能力 | 规则 |
|---|---|---|
| 主炮改造 | 穿透、追踪、多重、爆破，各 3 级 | 互相兼容、累积 |
| 自动支援 | 雷球、分身、彩虹光束、冰晶、磁吸星砂，各 3 级 | 同时只带一个；换新的先展示前后对比 |
| 大招改造 | 雷霆、冰封、连爆、星砂回收，各 2 级 | 同时一个 |
| 联动 | 两件前置都拿到才进候选 | 见下表 |

**联动表**：

| 联动 | 前置 | 效果 |
|---|---|---|
| 贯穿终点爆炸 | 穿透 + 爆破 | 穿透子弹最后一下炸开 |
| 蜂群同步开火 | 追踪 + 分身 | 分身跟着主炮开火，子弹追踪 |
| 追踪雷链 | 追踪 + 雷球 | 追踪弹命中时放电 |
| 散射冰晶 | 多重 + 冰晶 | 侧翼子弹冻住敌人 |
| 雷爆连锁 | 爆破 + 雷球 | 雷击标记，爆炸再放电 |
| 彩虹烟火 | 爆破 + 彩虹 | 爆炸变成彩色烟火 |
| 星砂散射 | 多重 + 磁吸 | 吸到星砂就射出星弹 |

**流派**（`BUILD_PATHS`）：每个流派 = 两件组件 + 一个联动。共 7 条：
- 贯穿爆破
- 追踪蜂群
- 追踪雷暴
- 散射冰晶
- 烟火
- 雷爆
- 星砂散射

大厅的“下一局目标”、暂停页、结算页、升级卡片上的“★目标流派”，都读同一个来源（`buildPlan`）。

**奖励池规则**：
- 第一次固定是穿透 1 / 追踪 1。
- 第二次：一个已有方向的升级 + 一个兼容的新方向。
- 第三次保证至少一个能联动。
- 连续两次没有能升级的项，就强制给升级。
- 满级、无效、缺前置的项不进候选。
- 第一只厚甲怪之后：一个“集中打单体”的方案 + 一个“清一片”的方案。

### 3.2 测量（`node tools/report-sim.js js 4`）

测量方法：机器人按 7 个流派各追一遍，打 1-1、1-2、1-3，共 84 局。
- “基线”：2026-10-06 打磨前。
- “打磨后”：同一天本轮改完。基线之后机器人学会了躲白线，所以 1-3 胜率不能直接比，见 lessons TP7。

| 指标 | 基线 | 打磨后 | 目标 |
|---|---|---|---|
| 一直没拿到任何联动的局 | 41 / 84（49%） | 5 / 84（6%） | ≤ 1/3 |
| 第一个联动出现时间（中位） | 115 秒 | 99 秒 | 越早越好；策划原定 ≤ 60 秒，受开局几个装置的位置限制 |
| 追到自己目标流派联动的比例 | 8–42% | 25–100%：三条 100%，其余 25–67%。机器人会拿别的流派先到的联动 | 玩家能把一局引向自己想要的流派 |
| 只加数字的选择 | 10% | 10% | ≤ 50% |
| 局与局重合度 | 0.30 | 0.32 | ≤ 0.6 |
| 各流派胜率 | 75–92% | 75–100% | 差 ≤ 25 个百分点 |
| 总胜率（推荐等级） | 85%（1-3 54%） | 92%（1-3 86%） | 第一章终点不设成长墙 |

**结论**：
- 打磨前：选择本身不是只加数字；问题在于随机决定了流派能不能成，玩家没法引导，一半的局到 Boss 都没成型。
- 打磨后：几乎每局都能凑成联动，玩家也能把一局引向自己想要的流派。

### 3.3 Build 方案【本轮已做】

**流派引导**（`aimPlan`）：每一局都有一条“正在追的流派”。
- 单人：大厅设了目标流派，并且你还没走到别的流派上，就追大厅的目标。
- 其他情况：追离当前 Build 最近、还没做完的那条。
- 联机：只看自己的 Build，各端一致。

**候选怎么出**（第一次固定是穿透 / 追踪，从第二次起按下面的顺序）：
1. 能凑的联动一出现就给，哪个装置都给。
2. 如果这个联动属于别的流派，而自己流派还缺的那一件也在池子里，两张卡就是“现在拿这个联动”对“接着凑自己的流派”，这是真正的取舍。
3. 没有能凑的联动时，一张卡给本局流派还缺的那一件（这个装置的池子里有的话），另一张照常随机。
4. 第二次选择：一张是已有方向的升级，一张是新方向。
5. 第一只厚甲之后的“集中 / 清一片”二选一，优先给本局流派缺的那一件。

**卡片和推荐**：
- 卡片上的“★目标流派”和大招键的推荐读同一个计划。
- 推荐顺序：联动 > 目标流派件 > 能凑联动的件 > 升级。

**改造写在子弹上**（每一发都看得见 Build）：

| 改造 | 子弹上的样子 | 满级 |
|---|---|---|
| 穿透 | 金色长光轨，等级越高越长 | 白金光枪 |
| 追踪 | 沿真实飞行路线弯过去的青色尾迹 | 尾迹带星屑 |
| 爆破 | 橙色引信圈，越高级越大、闪得越快 | — |
| 多重 | 并排的几路 | — |

每发一次，炮口都会闪一下，颜色是最高级那项改造的颜色。

**验证编队来两波**：升级后用同类敌人验证，第二波 1.6 秒后来。新能力要有足够的东西打，力量感才落地。

### 3.4 升级仪式【已做】

完整仪式按九步走：
1. 触发（0.3 秒回应）；
2. 变形（房子折成转盘，核心展开成水晶轮）；
3. 滚动（先快后慢）；
4. 真实升品质：结构、颜色、声音都变，只升不降；
5. 揭晓；
6. 二选一：飞进候选圈，停 0.3 秒确认；单人不限时；
7. 中央展示；
8. 飞进真实槽位；
9. 验证编队。

**奖励焦点**：
- 从变形到入槽，战场以 0.1 倍速运行，并且去饱和、变安静。
- 飞机稳住，有护盾；不刷怪，不发起新攻击。
- 关卡计时、连杀和冷却都暂停。
- 入槽后有 0.8 秒保护过渡。

**仪式长短**：
- 首个重要强化、第一次联动、高品质奖励用完整仪式，每局 2–3 次。
- 重复升级用短仪式。
- 资源掉落直接吸入。

**数据与表现**：确认选择的那一刻就写入数据；飞入只是表现。中途退出或重连只补展示，不重抽，不重复发。

## 4. 关卡、节奏与刷怪

### 4.1 结构【已做】

**结构单位**：
- 一章 3 关。
- 一关是一次完整出击，现在实测约 3–4 分钟。策划原定 6–8 分钟。
- 只在出击结束时结算。

**目标链**（`STAGE_PLANS`）：一关由一串主目标组成。每个目标都按同一个顺序走：
1. 看见障碍；
2. 成长机会（地图装置或精英核心）；
3. 用同样的敌人验证自己变强了；
4. 7 秒优势窗口；
5. 预告下一个威胁（2.4 秒）；
6. 再上压力。

**目标链的规则**：
- 前一个目标完成才推进。
- 普通杂兵一直都在。
- 同一时间只有一个大焦点：升级仪式、惊喜变身、目标入场，其余排队。

**各关目标链**：

| 关 | 目标链 | 新东西 |
|---|---|---|
| 1-1 梦灯海湾 | 怪群（梦灯屋）→ 第一只厚甲（风车塔）→ 厚甲编队（星砂矿，救援吊舱）→ 带队精英（核心）→ 后方追兵 → 月亮怪 → 泡泡小队长 | 厚甲阶梯、后方追兵、月亮惊喜 |
| 1-2 纸船灯河 | 怪群 → 裂缝钻出的厚甲 → 上下钻出的编队 → 残骸刷怪核心 → 带队精英 → 贴纸拟态 → 裂纹闹钟队长 | 上下入口、刷怪核心、界面拟态 |
| 1-3 失眠钟塔 | 怪群 → 后方绕来的厚甲 → 远处推近的编队 → 空间裂缝 → 带队精英 → 拟态梦灯屋 → 失控闹钟 | 前压、裂缝、章 Boss |

### 4.2 刷怪器规则【已做】

**背景杂兵**：
- 按本关 fill 速度持续出兵：2.3、2.7、3.1 只/秒。
- 编队有 line、vee、snake、wall、swarm 等阵型。
- 杂兵始终从右侧或预告过的入口进场。

**积压保护**：
- 场上活着超过 24 只、持续 3 秒，就推迟下一队 3 秒。
- 这不改变目标，也不送奖励。

**主目标入场方式**：
- shell：场景壳体破开；
- rift：裂缝；
- rear：后方弧线；
- drop：上下；
- crack：裂纹；
- push：背景前压；
- front：前方。

**惊喜**：每关最多一次主要惊喜，有预兆：
- 月亮怪：先打碎片，再打核心；
- 贴纸拟态：真实 HUD 永远可信；
- 拟态梦灯屋：打倒照样有奖励。

### 4.3 地图物件【已做】

| 物件 | 动作 | 回应 | 奖励 |
|---|---|---|---|
| 梦灯屋 | 碰一下门前的铃铛 | 屋子变成转盘 | 主炮改造二选一 |
| 风车塔 | 穿过宽风环 | 吹开入口，一排敌人被推到炮口前 | 优势在前，再给二选一 |
| 星砂矿 | 碰矿核，把它拖到标记的岩壁 | 炸开新航道 | 强化或联动二选一 |
| 救援吊舱 | 碰吊舱，沿光带护送到修理点 | 伙伴加入（家园 §8） | 支援二选一 |
| 精英核心 | 碰一下精英掉下的核心 | 展开成水晶轮 | 稀有二选一 |

相邻两个互动不用同一种操作、同一种结尾。互动完成后要留下变化：灯亮着、裂缝、跟随的伙伴、开放的航道。

**鱼群潮**（推压与喘息，`swell`）：
- 主目标进行中每隔一阵来一波：12 秒后第一次，之后每 10–16 秒，越往后的目标越勤。
- 波次内容：一大群一发就散的杂兵，右边缘先起一道往里推的波光（0.9 秒预告）。
- 数量 = 12 + 3 × 本局已选的升级数，最多 30。越强越能割草，不加血。
- 第 4 个目标起，鱼群后排混几条会开火的星星鱼。
- 杂兵各掉 1 颗星砂，不算“积压”。
- 屏幕上活着的已经有 24 只就跳过这一波（同屏上限）。

**背景杂兵**：越往后的目标越密（每个目标 +6%）。

**公平规则**（节奏报告统计“不公平受击”）：
- 敌人出现 0.5 秒内（入场演出开始算出现）不撞人、不开火。
- 屏幕外生成的子弹作废。
- Boss 从中心放的弹改从表盘边缘出来，表盘始终看得清。

**Boss 战中途也有奖励节拍**（`bossBreak`）：每打掉一段血，星砂从 Boss 身上喷出来、大招充一截。不回血：Boss 仍是一关里最难的一段。

## 6. 手感与反馈

**通用原则**：
- 反馈强弱跟时刻的稀有度和重要性一致。
- 频繁的时刻从不打断操作。
- 稀有、重要的时刻是仪式：先蓄势，再释放、落地、余波。
- 一切变化都要有动画：数字滚动、图标飞进槽位、目的地有回应。

### 6.1 反馈时刻表

现状为 2026-10-06 盘点。【本轮】改动写进“目标”列。

| 时刻 | 频率 | 档 | 现状 | 目标 |
|---|---|---|---|---|
| 子弹命中多血敌人 | 每秒数十次 | 局部 | 白色辉光、小点；没有声音、没有后退 | ≥ 3 个通道：白闪、受力方向小后退、轻命中音（同类限频）、碎屑 |
| 普通怪击杀 | 每秒数次 | 小 | 接触闪光、挤压、顺子弹方向的碎片；击杀音随连杀升调 | 保持 |
| 厚甲命中 | 持续 | 局部 | 金属脆响、甲屑、轻微后退；裂纹随阶段加深 | 保持 |
| 破甲 | 每局约 10 次 | 中 | 顿帧 45 毫秒、轻震、断裂音、甲片抛落、“破甲！” | 保持 |
| 精英击杀 | 每局约 3 次 | 大 | 顿帧 55 毫秒、震动、终结音、14 份星砂 | 加入掉落喷发和落点回应 |
| 升级仪式 | 每局 6 次 | 大（仪式） | 九步仪式 | 揭晓与入槽落地见评审 |
| 宝箱 | 偶尔 | 大 | 碰到立刻入账，飘一行字 | 蓄势（抖动、开盖）后释放，奖励一件件飞回 |
| 目标完成 | 每局 7 次 | 小 | 音效 + 横幅 | 顶栏打勾、进度填满，再滑到下一个目标 |

**震动上限**：一下小震，不超过 6 像素、0.15 秒。现状：
- 震动量 = trauma² × 16 像素，按每秒 1.8 衰减。
- 通关 shake(1) 有 16 像素、约 0.55 秒，超过上限。

**顿帧**：只用在破甲、精英、Boss 部位、受伤；0.5 秒内最多一次。普通命中只做局部反应。

## 9. 联机（2–4 人）

**同步方式**：用户裁定，只同步操作，确定性模拟。
- 每秒 30 个操作帧，每帧 4 个模拟步（120 Hz）。
- 每帧 5 个字符，每 30 帧比对一次状态哈希。
- 转发：现在用自己的服务器（`server/relay.js`），之后接 Steam。

**合作**【已做】：
- 各拿各的：每人自己的 Build、升级、掉落、资源。
- 全队统一进入升级：选好的人等队友。限时 25 秒，到时自动选推荐。
- 击毁救援：
  - 队友飞进宽救援圈停约 2 秒，就地救起；
  - 回约 40% 生命，有 2 秒保护；
  - 不自动复活；救援圈里的敌弹会化掉；
  - 在线的人全部倒下才算失败。
- 房主断线，其余人继续。
- 断线保留席位 60 秒：断线中原地占位，回来后按操作记录追上；超时才移除，主动退出直接移除。
- 刷新页面能回到原对局。
- 房间有准备确认和 3 秒倒计时。
- 同一局只结算一次（奖励账本）。

**对抗**【已做，自由竞争 2–4 人】：
- 每人一条航道。三段，每段 120 秒，计时在升级时暂停。
- 每段的节奏：
  - 风塔目标分；
  - 干扰洞口（矿甲列阵或侧风，每段一次，排队不叠加）；
  - 冲突区直接对攻。
- 被击毁后 3 秒原地复归。
- 以目标分为主。
- 可以选“统一属性”。
- 结算拆解每一项得分。

**未做**：
- 1 对 1 和 2 对 2 分队；
- 公共匹配、Steam 好友与大厅；
- 进入他人家园与权限；
- 成长来源核对；
- 快捷沟通（标记、求救、等我、感谢）；
- 关内分岔共识；
- 多人难度随人数变化的细则：优先增加敌阵和来源，Boss 按开局人数加有限生命。

**新系统一律先回答“联机时怎么办”**：
- 世界状态各端一致；
- 每人各自存档；
- 房间里能看到彼此的进度。

## 10. 美术方向（Q 版规范，一直适用）

**情绪比例**：可爱 60%、梦幻 25%、轻微诡异 15%。

**画法**：
- Q 版手绘 2D：圆润轮廓、大色块、软边发光、纸张纹理、漂浮物。
- 现在全部是 Canvas 程序绘制。

**线与光**：
- 线条用深蓝紫，不用纯黑。外轮廓比内线粗。
- 主光来自上后方的月光或梦灯。

**颜色**：
- 主角暖白和金黄梦灯；能量青紫；受伤珊瑚红。
- 背景不能比战斗元素更亮，不能用弹幕的高亮色。
- 弹幕靠形状、速度和颜色共同区分：
  - 粉色圆弹；
  - 蓝色菱形；
  - 金色星弹；
  - 白色预警线：先出现透明细线，0.3 秒后变亮，0.8–1.2 秒后攻击。

**造型**：
- 精英不能只是普通怪放大换色，要多一个识别元素。
- Boss 占画面横向 20–35%，每个阶段有明显变化。

**构图**：主角在左侧 25–35%，Boss 在右侧 65–80%，中间留给弹幕。

**禁用方向**：
- 写实射击风；
- 纯黑红恐怖风；
- 所有角色都是白色圆球；
- 所有弹幕都是圆形；
- UI 只有文字。

**原创**：角色、轮廓、音乐、图标、关卡构图全部原创。

## 11. 文字与界面

**文字规则**：用户裁定，见 §15。
- 机制和技能说明一律写成：图标 + 名字，换行一句话，不写数值。
- 强弱用箭头表示：绿 ▲、红 ▼，1–3 个。
- 显示的数字必须等于实际用的数字。

**屏幕上的信息**：
- 顶栏只显示一个主目标，外加一个可选的地图目标。
- 屏幕中央留给战斗；过期的标题卡要替换或淡出。

## 14. 测量与验收

**测量工具**（都在 `tools/`）：
- `smoke-sim.js`：三关通关、家园因果链。
- `home-sim.js`。
- `mp-sim.js`、`relay-test.js`、`net-bot.js`：联机。
- `report-sim.js`：构筑报告 + 节奏报告。
  - 7 个流派 × 3 关的机器人对局。
  - 每秒采一次 `World.pacing()`：强度、累计奖励、不公平受击、有敌人在场时的每秒伤害。
- `shoot.js`：无头 Chrome 打真实关卡，截商店主图、5 张截图和预告片 9 帧。

**节奏报告的目标**：

| 指标 | 目标 |
|---|---|
| 第一次行动 | ≤ 8 秒 |
| 最长平静 | ≤ 40 秒 |
| 连续高压 | ≤ 60 秒 |
| 无奖励 | ≤ 75 秒 |
| 后段 ÷ 前段 | ≥ 1.3× |
| 火力成长 | ≥ 2× |
| 不公平受击 | 0 |
| 输局聚集 | 没有一段占 40% 以上 |

**构筑报告的目标**：
- 流派胜率差 ≤ 25 个百分点；
- 没拿到成型件的局 ≤ 1/3；
- 只加数字的选择 ≤ 50%；
- 局与局重合度 ≤ 0.6。

**原有的数据验收**（`METRIC_TARGETS`）：

| 指标 | 目标 |
|---|---|
| 首次击杀 | ≤ 5 秒 |
| 首次二选一 | ≤ 30 秒 |
| 普通怪平均击杀 | ≤ 0.5 秒 |
| 战斗段空档 | ≤ 1.2 秒 |
| 最长无主目标 | ≤ 10 秒 |
| 第一只厚甲 | ≤ 5 秒 |
| 升级后厚甲 | ≤ 3 秒 |
| 大招满库存闲置 | ≤ 20 秒 |
| 主动互动 | ≥ 3 次 |
